# Pulse Markets — Backend

REST API for the Pulse Markets prediction app. Django REST Framework + JWT auth
+ an XGBoost ML pipeline that predicts whether an asset's price will move up,
down, or stay flat over a given horizon — with honest confidence framing.

> The model does NOT claim to beat the market. Weak signals are reported as
> **"NO CLEAR SIGNAL"** rather than a false-confident up/down call.

## Features

- **Auth** — register, login, refresh, change password (JWT via SimpleJWT)
- **Assets** — 150+ seeded stocks, forex pairs, and crypto with live yfinance
  validation on creation; delisted assets auto-flagged on refresh
- **Predictions** — cached per asset + horizon, generated by the scheduled
  `refresh_predictions` command (not live-per-request), with honest confidence
  thresholds
- **News** — economic calendar via FRED (CPI, Fed funds rate, unemployment) and
  market headlines via NewsAPI; degrades gracefully without API keys
- **Watchlist** — per-user saved asset lists

## Project structure

```
config/          Django settings, urls, wsgi, asgi
accounts/        Custom User model + JWT auth
assets/          Asset + PriceSnapshot models/views
predictions/     Prediction + ModelMetric models/views
news/            EconomicEvent, MarketNews, AssetNews
watchlist/       Watchlist + WatchlistItem

```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py seed_assets            # validates tickers live against yfinance (add --skip-validation to skip)
python manage.py refresh_predictions    # generates predictions for all active assets (slow, ~150 assets)
python manage.py runserver
```

## Schedule predictions

Refresh predictions on a schedule (Render cron / cron job):

```bash
python manage.py refresh_predictions --horizon 5d
```

Optionally refresh news on a schedule too:

```bash
python -c "from news.services import refresh_all_news; print(refresh_all_news())"
```

## News API keys (optional)

The news app works fully without keys (endpoints return empty lists) but to
populate real data set in `.env`:

```
FRED_API_KEY=your-key        # from https://fred.stlouisfed.org/docs/api/api_key.html
NEWS_API_KEY=your-key        # from https://newsapi.org
```

## Deployment (Render, free tier)

- **Web service**: `gunicorn config.wsgi`
- **Background + cron**: Render free tier supports scheduled jobs that run a
  command; run `python manage.py refresh_predictions` on a schedule (e.g. daily).
- **Database**: set `DATABASE_URL` to your Postgres URL in production
  (defaults to sqlite locally).

## Prediction model honesty

The `ml/` package uses walk-forward time-series validation (no shuffling, no
peeking) and reports accuracy against a naive baseline. It deliberately
demonstrates why "R² = 0.99" on price prediction is misleading (regression just
tracks price autocorrelation). Direction prediction is the honest metric.

Confidence threshold: `|probability_up - 0.5| >= 0.06`, i.e. the model only
issues a bullish/bearish call when the probability is clearly away from 50%.
Otherwise it returns **"NO CLEAR SIGNAL"**.
